# v0.12.0 · 温暖书房

本版将桌面界面整理为「我的课程」「转写任务」两页，采用米白与墨绿主题。详细日志默认折叠，常用操作和下一步提示直接展示。

## 更新内容

- 课程支持搜索、跨课程保留勾选和只选未转写；刷新课程不会自动创建任务。
- 任务支持状态筛选、详情和实际输出文件入口。运行中新增待办留到下一批，由用户点击开始。
- 设置分为语音识别、文字整理、文件保存、高级设置。取消和检查连接不保存修改；当前批次使用配置快照。
- 小窗口收起装饰标题，课程侧栏可折叠，设置内容可滚动；保留系统标题栏与键盘操作。
- 补齐本地识别的 NumPy 打包依赖，修复独立启动时明确标注学号的日志脱敏。

## 下载与使用

从 [GitHub Release](https://github.com/HMS-Victoria/ecnu_lulu/releases/tag/v0.12.0) 下载 ZIP，完整解压后运行「大夏学堂转写助手.exe」。请保留整个文件夹及 `_internal`，不能只复制 EXE。

程序包含 Python 运行环境、ffmpeg 和 ffprobe。**浏览器与识别模型未内置**：学校登录需要准备可用的浏览器；本地识别需要相应模型，云服务需要用户自己的配置。服务提供方可能收取识别费用。

## 从旧版升级

将新版解压到新目录，保留旧版作为备份。配置与登录信息继续使用本机用户目录；旧版旁的任务库、缓存和输出不会自动迁移。需要继续旧任务时，先关闭两版程序并备份旧目录，再将旧版的 `data`、`cache`、`output` 复制到尚未创建任务的新版目录。不要用两份程序同时操作同一份任务库，也不要把旧 `_internal` 覆盖到新版。

## 验证范围

- 常规离线回归：426 项通过，1 项慢模型测试按原规则跳过。
- 已验证模拟平台与识别服务下的转写流程、缓存恢复、任务身份、配置保留，以及两种分辨率和 100%/125%/150% 缩放。
- 成品验证覆盖冻结态自检、合成音频处理、导出编码、状态库、页面交互和本地引擎导入；Windows 原生检查覆盖窗口启动与正常退出。
