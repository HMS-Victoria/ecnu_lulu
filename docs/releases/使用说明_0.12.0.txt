大夏学堂转写助手 v0.12.0 · 温暖书房版

启动
双击同目录下的“大夏学堂转写助手.exe”。
如果使用 ZIP，请先完整解压，再启动程序。
移动或分享时请复制整个文件夹，保留 _internal 文件夹；不要只复制 EXE。

开始使用
1. 点击“登录学校账号”，在学校页面手动完成登录。
2. 在“设置 → 语音识别”选择服务并完成配置。
3. 点击“刷新课程”，勾选录播，点击“开始转写”。
4. 在“转写任务”查看进度，完成后选中任务打开文稿、字幕或笔记。

新版操作
“加入待办”只排队；运行期间新增待办留到下一批，由你点击开始。
设置分为语音识别、文字整理、文件保存、高级设置；高级参数按需展开。
底部“查看详细日志”可展开运行记录。

组件与数据
本包包含程序运行环境、ffmpeg 和 ffprobe，不需要另外安装 Python。
学校登录需要可用的登录浏览器；浏览器和语音识别模型不包含在 ZIP 中。
已在本机安装并配置过的登录浏览器可继续使用；缺少组件时请查看“使用检查”。
本地识别需要准备相应模型；本次打包没有下载模型或验证模型转写效果。
云端识别需要用户自己的服务配置，可能由服务提供方计费。

程序默认在本程序目录下保存 output、cache、data 和 logs。
登录信息与配置使用本机原有用户目录。旧版程序旁的任务库和输出不会自动搬入新目录。
如需继续旧任务，请先备份原目录后再迁移；不要在两份程序中同时操作同一份任务库。

本次打包使用隔离数据验证，不含真实账号、服务密钥、课程录播或转写文稿。
